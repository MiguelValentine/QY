# CreateObj 与 index.fcc 启动边界

本文记录 `CLIENT/objsys.dll` 中内置回调 `CreateObj` 的静态证据，以及当前真实启动停点。证据来自随仓库保存的 PE 反汇编；没有执行原生客户端来验证该回调。

## 登记

初始化代码在 `0x1005a284–0x1005a28e` 将名称地址 `0x100a2d8c`（`"CreateObj"`）和回调地址 `0x10058d70` 交给通用登记器 `0x1005ab10`。登记器对名称调用 `FBase.dll!#858` 生成名称哈希，并把哈希、名称指针和回调地址写入 `0x10121c74` 指向的登记表。脚本运行时使用此名称哈希找到回调；其值不同于传入的类名哈希。

## 参数与工厂调用

回调 `0x10058d70` 从 VM 参数读取值：

- 类型 3：直接以 `FBase.dll!#788` 取得字符串哈希。
- 类型 6：以 `#785` 读取索引 0，并要求其类型为 3；以 `#786` 确认至少有两项，再以索引 0 的字符串计算类名哈希。
- 类型 6 的其余项被规整为初始化参数：若只有两项且索引 1 不是类型 6，则 `#784` 将索引 1 复制到临时 VM 值；否则 `#747` 复制整个 tuple，再由 `#766` 删除索引 0 的类名。此时工厂收到移除类名后的 tuple。类型检查或形状不符则进入错误路径。

单字符串类型 3 分支不经过 tuple 参数规整。通用路径从回调栈位置 `[esp+0x2c]` 取宿主对象，作为 `ECX` 调用 `0x10065890`；第一个栈参数是类名哈希，第二个栈参数明确为 `0`。因此 `CreateObj("Class")` 通过当前宿主对象查找/创建类对象，但不向工厂提供初始化数据块。

`0x10065890` 在 `ECX` 中接收该宿主对象，并以类名哈希查找/创建目标对象。找不到对象时会沿宿主对象的 `+0xa8` 父链查找上下文的 `+0xb8` 类表，命中类记录后递归调用自身。成功后把类名哈希写入新对象 `+0x10`。其第二个栈参数为可选初始化数据块：非空时检查该块的 `+4` 容器，并将其中三个字段复制到目标对象 `+0xa4` 所指结构；`CreateObj` 固定传入空值，所以该初始化块复制路径被跳过。超过对象数阈值的诊断分支不改变以上常规调用参数关系。

## 返回对象与后续分派

工厂返回非空对象后，`0x10058ea1–0x10058eae` 调用 `FBase.dll!#799`，把原 VM 目标值设置为类型 4，并写入对象引用相关字段。若临时 VM 值类型非 0，回调以新对象作为 `ECX`（接收对象），以原宿主对象 `+0x90` 作为调用上下文，并将类名哈希与规整后的 VM 值传给 `0x1005ab90`。对象 `+8` 的标志条件满足时，它还以相同接收对象和上下文、事件哈希 `0x376d2b34` 及空参数调用该 helper。`0x376d2b34` 对应 `OnCreate`，参见 [new-constructor-call.md](new-constructor-call.md)。这些后续分派不是 `0x65890` 的第二个参数，也不是它的初始化块。

`index.fcc:0x1670` 的调用目标哈希 `0x0e9c89f6` 对应 `CreateObj`，
它出现在 `land` 同名构造方法内，调用目标不等于之后创建的子对象类名。

## Go 实现

运行器在接收对象的原生成员分派未处理时识别 `CreateObj`。显式
`receiver.CreateObj(...)` 使用 receiver 查找类并作为新实例所属对象，
不借用当前执行对象。隐式调用仍允许当前词法作用域中的同名脚本函数遮蔽。
实例创建复用 `new` 的工厂、类体和事件流程。

单字符串只创建实例并触发已登记的 `OnCreate`。带参数时只取类名之后的
实参调用同名方法，并忽略其返回值。原生 VM 对第二项为 tuple 的两项
输入保留一层外部参数容器；Go 因此保留嵌套 tuple 为单个实参，而不把
`CreateObj("Class", (a,b))` 错展为两个实参。单个组合值作为整个输入时，
需至少有两项。类名之后仅有一个空值时，原生临时 VM 类型为0，
跳过同名方法，但仍触发创建事件。

Go 对参数错误和未实现能力立即报错；不把原生的日志后继续路径用来
忽略缺项。动态初始化块仍不由该接口实现。

2026-10-16，真实入口测试已越过 `0x1670`，进入所创建子图片的构造
方法，并首先停于 `index.fcc:0x116c` 的图像成员 `0x6c181c97`。
这不代表子对象初始化全部完成或已进入游戏。
