# `wnd` 对齐属性静态核对

## 结论

`wnd` 成员初始化序列将 `halign` 与 `valign` 登记为写属性，回调分别为
`0x1004ebc0` 和 `0x1004eca0`。setter 要求对象 `+0xa8` 存在父对象；成功时
同步改写自身坐标偏移 `+0x14`（水平）或 `+0x18`（垂直）。偏移按父对象对应
矩形尺寸乘百分比、除以 100，再加可选整数偏移计算。

## 登记和初始值

- `0x1004f423–0x1004f42f` 将字符串 `halign`（`0x1009f614`）与 setter
  `0x1004ebc0` 交给 `0x1004d470` 登记；哈希为 `0xf256cedf`。
- `0x1004f434–0x1004f440` 将字符串 `valign`（`0x1009f60c`）与 setter
  `0x1004eca0` 登记；哈希为 `0x7725fd91`。
- 此处使用 setter 登记入口 `0x1004d470`，该相邻序列未见这两个名称调用
  getter 登记入口 `0x1004d4d0`；因此证据只确认写访问器。
- `wnd` 构造函数 `0x1005d720` 在 `0x1005d792–0x1005d79c` 清零从对象
  `+0x14` 开始的 `0x69` 字节，故 `+0x14`、`+0x18` 初始均为零。它还在
  `0x1005d7c1` 将对齐/自动布局配置指针 `+0x80` 置零。
- 首次 setter 调用若 `+0x80` 为空，会建立并清零 `0x24` 字节配置记录
  （`0x1004ec0a–0x1004ec33`、`0x1004ecea–0x1004ed13`）。`halign` 写入
  记录首字节及 `+1` DWORD；`valign` 写入 `+5` 字节及 `+6` DWORD。对应
  配置字段的初始比例和附加量都是零。

## 参数与坐标计算

两个 setter 都先检查接收对象 `+0xa8`；为空即返回失败。随后调用
FBase #768，要求至少成功抽取一个 tag 1 整数（返回值与 1 比较，少于 1
则失败）。调用点为两个整数输出描述留位；第二个输出槽在调用前明确清零，
所以只提供一个整数时，第二个加数为零。

对两项输入可用情况，setter 将第一个值的低 8 位保存为无符号比例字节
`p`，第二个 tag 1 整数保存为有符号附加量 `d`。本次调用提供的整数个数
不足两项时，第二项沿用零初始化值。结合机器指令中的乘法、常数
`0x51eb851f`、符号修正和右移，除法实现的是有符号整数除以 100（向零截断）。

- `halign`：`0x1004ec3c–0x1004ec8a` 读取父对象矩形宽
  `parent[+0x2c] - parent[+0x24]`，计算
  `self[+0x14] = (parentWidth * p) / 100 + d`。
- `valign`：`0x1004ed16–0x1004ed66` 读取父对象矩形高
  `parent[+0x30] - parent[+0x28]`，计算
  `self[+0x18] = (parentHeight * p) / 100 + d`。
- 若 `p == 0`，setter 不执行上述坐标写入；配置记录仍保存比例和附加量。
  `halign` 成功计算时另将对象 `+0x48` 按位或 `0x8000`
  （`0x1004ec75–0x1004ec8d`）；`valign` 代码没有对应的该写入。

坐标偏移的即时消费可见于 `0x1005d410–0x1005d557`：绘制/区域计算路径
把对象 `+0x14` 加到矩形的水平边界，把 `+0x18` 加到垂直边界。因此 setter
改变的是对象矩形相对于既有坐标的 x/y 偏移，不是直接改写矩形的
`+0x24/+0x28/+0x2c/+0x30` 边界，也没有证据表明它本身触发 OS 窗口移动。

## 参数边界

FBase #768 的已存证行为是：顶层 tuple 会按源 tuple 长度遍历，调用点提供
的请求数不是 tuple 循环上限。这里的 setter 只布置两个 tag 1 输出描述，
且只检查返回值至少为 1。单值和两值的行为由上述局部输出槽和成功门槛支持；
超过两个 tuple 元素时，额外迭代会读到调用点未定义的后续抽取描述，不能
据此声称多余值会被忽略或得到稳定处理。见
[`fbase-argument-extraction.md`](fbase-argument-extraction.md)。

本记录依据 `analysis/disassembly/objsys.annotated.asm` 静态指令，不代表已
观测原版运行时或实际渲染结果。
